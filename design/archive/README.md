# The Design archive

Retired plans, prompts and working notes from the Design zone. They are kept because the record
of the struggle is part of the work: each file was true when it was written, and each is here so a
retired instruction can never look current. Nothing in this folder was deleted.

## The live records

- `../CHANGELOG.md` — the zone's running log: the PostHog startup pass, the Design box, the gate
  removal, and the work before them.
- `../POSTHOG-STARTUP-TRIM-2026-10-24.md` — the analytics application's startup pass.
- `../../frontend/src/rooms/design/PLAN-sovereign-design.md` — the current plan for the room.
- `../../frontend/src/rooms/design/PLAN-tools-and-ux-chat.md` — the Tools and PostHog chat plan.
- [the top-level README](../../README.md#sovereign-shell-audit-2026-10-24) — the standing shell and shared-dependency audit.
- `../../frontend/src/rooms/design/CHANGELOG.md` — the room's own log.

The analytics application's own notes stay with `posthog-master/`; that is the application's
shelf, not the room's.

## The rule

A retired plan is archived with a reason, never deleted. The same rule holds in the Governance
room. The live folder stays small enough to read; the archive holds the wrong turns and the
arguments that led to the right ones.
